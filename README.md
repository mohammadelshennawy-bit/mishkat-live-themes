# Mishkat Live Themes V1.0

Independent Android application: `com.mishkat.livethemes`. Based on the V2.2 source.

Upload all files including `.github/workflows/android.yml` to the new repository. Open Actions → Build Android APK → Artifacts → mishkat-live-themes-apk.

APK build and device testing are required. Prayer times are approximate. For future updates use a stable signing key (ANDROID_DEBUG_KEYSTORE secret).
